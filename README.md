# osadainduwara.github.io

My personal portfolio website. Built this to showcase my work in AI/ML and full-stack development.

## What's in here

- **Home** – Quick intro with animated background
- **About** – Who I am and what I do
- **Projects** – Stuff I've built (ML pipelines, chatbots, mobile apps, etc.)
- **Resume** – Education, experience, and downloadable PDF
- **Skills** – Tech stack I work with
- **Blog** – Coming soon, planning to write about GenAI and MLOps
- **Contact** – Form to reach me

## Tech used

Nothing fancy:
- HTML/CSS/JS
- Bootstrap for layout
- Particles.js for the hero background
- Formspree for the contact form

## Run locally

```bash
npx serve .
```

Then open `http://localhost:3000`

## Deploy

Just push to `main` – GitHub Pages handles the rest.
